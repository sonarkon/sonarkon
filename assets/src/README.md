Card templates for the profile README (800×400, dark style matching Common Shrew).
Render: `npm i @fontsource/fraunces@5.1.0 @fontsource/inter@5.1.0 playwright`, then
`node render.js tba-builder.html ../tba-builder.png 800 400 1` and convert it to JPG.
The Common Shrew card is a downscaled copy of `docs/social-preview.png` from that repo.
